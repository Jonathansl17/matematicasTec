# Materias de Matemáticas en este repositorio

Este repositorio contiene material de estudio organizado por materia.

## Materias

| Materia | Carpeta | Estructura principal |
|---|---|---|
| Álgebra Lineal | `algebra_lineal/` | `primer_parcial`, `segundo_parcial`, `tercer_parcial`, `tutoriasalgebra`, material de cálculo y álgebra lineal |
| Cálculo Diferencial e Integral | `calculodiferencialeintegral/` | Apuntes y prácticas (límites, derivadas, integrales, análisis de funciones, exámenes) |
| Estadística | `estadistica/` | `practicas`, `examen1`, `examen2`, `examen3`, `material_examenes` |
| Investigación de Operaciones | `investigacion_de_operaciones/` | `clase1` a `clase15`, `tareas`, `examenes` |
| Matemática General | `matematica_general/` | `Primer parcial`, `Segundo parcial`, `Tercer parcial` |
| Probabilidades | `probabilidades/` | `primerparcial`, `segundoparcial`, `tercerparcial`, `practicas`, `examenes` |

## Resumen rápido del contenido

- Predominan archivos en formato PDF (`.pdf`) y Xournal (`.xopp`).
- También hay archivos de apoyo en formatos como `.py`, `.docx`, `.doc` y scripts.

## Nota

La carpeta `.git/` es interna de control de versiones y no corresponde a una materia.
